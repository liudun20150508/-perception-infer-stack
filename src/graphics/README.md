# 零依赖 CPU 光栅化器（能力点「游戏、图形引擎或仿真系统」）

本机**没有任何图形栈**（无 libGL / X11 / EGL / DRM，也没有浏览器），但那不等于图形做不了：
光栅化的每一步都能在 CPU 上实现。于是自研了一条最小图形管线，把布料仿真引擎导出的
真实网格无头渲染成图。

```bash
bash src/graphics/build_n_run.sh
```

## 管线

```
OBJ 解析 -> 模型/世界/观察变换 -> 透视投影 -> 屏幕映射
        -> 三角形光栅化(z-buffer, 透视校正重心插值)
        -> 兰伯特 + 半球环境光 + 边缘光 -> gamma -> PPM -> PNG
```

输入是 `06_仿真与图形/云之梦_布料仿真/output/wedding_dress.obj`（**26386 顶点 / 51928 三角面**，
带逐顶点法线）—— 即布料仿真引擎跑出来的真实网格。

## 踩坑（已记入 `../../docs/troubleshooting-log.md`）

- 首版**整屏空白**：背面剔除用了屏幕空间有向面积判绕序，但屏幕 Y 翻转后方向相反，
  把全部三角面剔没了；同时深度用的是 `1/Σ(w/z)` 而非 `area/Σ(w/z)`，跨三角形不可比。
  改为「不做背面剔除，交给 z-buffer」+「透视校正深度」后正常。

> 说明：这是**CPU 软件渲染**，不是 GPU compute（没有 compute shader / CUDA）。
> 它证明的是"图形管线理解 + 工程实现"，不等于 CUDA 图形证据 —— 不混为一谈。
